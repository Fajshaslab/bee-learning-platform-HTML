WAT IS VERBETERD?
- CSS- en JavaScript-lessen openen meteen het juiste editor-tabblad.

ZO INSTALLEER JE HET ZONDER JOUW VOORTGANG AAN TE RAKEN:
1. Maak voor de zekerheid een reservekopie van de huidige projectmap.
2. Open de ZIP. Daarin staat de map 'bee-learning-platform'.
3. Kopieer DE INHOUD van die map over de inhoud van jouw BESTAANDE map:
   C:\Users\fajsh\Desktop\BEE-Learning-Platform-AUTOTEST\bee-learning-platform
   Kies in Windows 'Bestanden vervangen' waar dit wordt gevraagd.
   VERWIJDER je bestaande projectmap NIET. Dit is een wijzigingspakket,
   geen compleet nieuw project.
4. Open de bestaande map in VS Code. Voer in de terminal uit:

      npm run check
      npm test
      npm run build
      git add .
      git commit -m "Improve BEE learning experience v2.3"
      git push origin main

5. Kijk in GitHub > Actions of publicatie en automatische tests groen worden.
6. Open de bestaande GitHub Pages-website en vernieuw met Ctrl+F5.
