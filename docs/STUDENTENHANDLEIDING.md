# BEE Learning Platform — studentenhandleiding

**Versie:** 2.3 · **Voor:** deelnemers aan het HTML-, CSS- en JavaScript-leertraject

**Website:** https://fajshaslab.github.io/bee-learning-platform-HTML/

## 1. Een account aanmaken en inloggen

1. Open de website in een recente browser, bij voorkeur op een computer of laptop.
2. Klik op **Registreren** onder het inlogformulier.
3. Vul je eigen e-mailadres in en kies een uniek wachtwoord van minimaal acht tekens.
4. Open de bevestigingsmail en bevestig je e-mailadres. Kijk ook in je spammap.
5. Ga terug naar het platform en log in met **Inloggen**.

Gebruik voor officiële studievoortgang altijd je eigen, bevestigde account. **Open demonstratie** is alleen om rond te kijken: de voortgang in die modus wordt niet officieel vastgelegd en hoort bij die browser.

**Wachtwoord kwijt?** Klik op **Wachtwoord vergeten?** op het inlogscherm en volg de herstelmail. Deel nooit je wachtwoord of herstellink met iemand anders.

## 2. Van het dashboard naar je les

Op het **Dashboard** zie je jouw voortgang en het onderdeel waarmee je verder kunt. Klik op **Verder leren** om de eerstvolgende onafgeronde les of modulecheck te openen. Via **Modules** kun je eerdere onderdelen teruglezen.

De cursus is bewust lineair. Nieuwe lessen en modules worden pas toegankelijk nadat alle verplichte voorgaande onderdelen zijn afgerond. Een afgeronde les mag je later opnieuw bekijken.

De leerroute bevat acht modules, 40 lessen en acht modulechecks. De lestijd is een planning, geen tijdslimiet.

## 3. Een les volgen

1. Lees eerst **Theorie en uitleg** en het uitgewerkte codevoorbeeld. De knop **Direct naar de opdracht** is er om terug te springen zodra je de uitleg al kent.
2. Lees bij **Praktijkopdracht → Zelf proberen** wat je moet bouwen en in welk bestand je moet werken.
3. Typ je code in de editor. Er zijn drie tabbladen: **index.html**, **style.css** en **script.js**. Het juiste tabblad voor de les staat normaal al open.
4. Bij HTML en CSS verschijnt je resultaat in **Live Preview**. JavaScript wordt in deze versie niet uitgevoerd; je kunt de JavaScript-code wel schrijven en laten controleren.
5. Klik op **Controleer mijn code** om gerichte feedback te krijgen. Gebruik eventueel **Toon hint** en verbeter je code.
6. Wanneer je oplossing aan de eisen voldoet, klik je op **Les officieel registreren**. Pas na de bevestiging van het platform staat de les als voltooid geregistreerd.
7. Lees ook **Verdieping en zelfcontrole** om je oplossing verder te begrijpen.

**Let op:** een positieve codecontrole is nog geen officiële lesafronding. Het platform moet de registratie door de server bevestigen. Een automatische controle beoordeelt basiseisen aan de code, niet of je alle concepten volledig begrijpt.

## 4. Modulechecks

Na alle lessen van een module verschijnt de verplichte **Modulecheck**. Beantwoord alle vijf de vragen en klik op **Modulecheck indienen**. Zijn niet alle antwoorden correct, dan kun je de vragen opnieuw beantwoorden. Pas na de serverbevestiging gaat de volgende module open.

De modulechecks zijn oefentoetsen. Ze zijn geen formele certificering of officieel examen.

## 5. Je code en voortgang bewaren

Er zijn **twee soorten opslag**:

- **Officiële voortgang:** afgeronde lessen en modulechecks worden na bevestiging bij je account opgeslagen. Je kunt deze voortgang op een ander apparaat terugzien.
- **Conceptcode:** je bewerkte bestanden worden lokaal opgeslagen en kunnen bij een ingelogd account ook met de server synchroniseren. Kijk naar de opslagstatus in de les. Gebruik zo nodig **Synchroniseer concept**.

Bij **Conceptopslag** vind je ook:

- **Lokaal opslaan:** bewaar je huidige code op dit apparaat.
- **Synchroniseer concept:** probeer je concept online bij je account op te slaan.
- **Export JSON:** download een reservekopie van je code voor deze les.
- **Import JSON:** laad een eerder geëxporteerd bestand van dezelfde les.
- **Begin lokaal opnieuw:** zet je lokale code terug naar de begincode; dit verwijdert je officiële lesvoortgang niet.

Als de applicatie een **opslagconflict** meldt, is het concept mogelijk op een ander apparaat gewijzigd. Kies niet blind een versie: exporteer eerst je huidige code als JSON. Je kunt daarna de serverversie laden of de lokale versie apart bewaren.

## 6. Als je geen internet hebt

Je kunt soms doorgaan met een **al geladen** oefening en die lokaal bewaren. Zonder verbinding kun je geen les of modulecheck officieel afronden. Controleer na herstel van de verbinding de opslagstatus en synchroniseer je concept indien nodig.

Een lokaal concept is geen gegarandeerde back-up: wis de browsergegevens niet voordat belangrijke code is geëxporteerd of online opgeslagen.

## 7. Veelvoorkomende problemen

| Probleem | Wat je zelf kunt doen |
|---|---|
| Geen bevestigingsmail | Controleer spam en of je het juiste e-mailadres hebt gebruikt. Meld een blijvend probleem bij je begeleider. |
| Wachtwoord vergeten | Gebruik **Wachtwoord vergeten?** op het inlogscherm. |
| Volgende les blijft op slot | Controleer of je op **Les officieel registreren** hebt geklikt en of de vorige modulecheck volledig afgerond is. |
| Code wordt afgekeurd | Lees de feedback, kijk naar het gevraagde bestand en controleer de opdracht en het voorbeeld. |
| Voortgang lijkt weg | Controleer of je bent ingelogd met hetzelfde e-mailadres, niet in **Open demonstratie**. |
| Concept is weg op een ander apparaat | Controleer de conceptstatus en **Synchroniseer concept** op het eerste apparaat, als dat nog mogelijk is. |
| Opslagconflict | Maak eerst een **Export JSON**; overschrijf niet zomaar een versie. |
| Sessie verlopen | Log opnieuw in. Maak bij twijfel eerst een export van je laatste code. |
| Preview toont niets | Controleer of je HTML/CSS hebt geschreven; JavaScript wordt niet uitgevoerd in de preview. |

## 8. Veilig werken

- Gebruik uitsluitend je eigen account. Deel je wachtwoord, bevestigingslinks en herstellinks nooit.
- Werk je op een gedeelde computer? Klik na afloop op **Uitloggen** en laat geen gedownloade JSON-bestanden met persoonlijke oefencode achter.
- Geef bij problemen aan je begeleider door **welke module/les**, **welke knop** en **welke foutmelding** je ziet. Deel geen wachtwoorden of toegangstokens.

**Onthoud:** **Verder leren → lees uitleg → maak oefening → controleer code → registreer les → modulecheck.**
